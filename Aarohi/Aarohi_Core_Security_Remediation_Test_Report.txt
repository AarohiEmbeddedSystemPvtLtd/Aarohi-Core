4. ITEM-BY-ITEM REMEDIATION DETAIL (14 CORE FINDINGS)
--------------------------------------------------------------------------------
1. SEC-C-001 (Critical) - Hardcoded Zoho SMTP Password
   File: Aarohi/Networking/MailHelpers.cs
   Remediation: Hardcoded password removed. Loaded via Windows DPAPI CurrentUser.
   Result: PASS (0 occurrences in code or binary)

2. SEC-C-002 (Critical) - Hardcoded Zoho OAuth Secret & Refresh Token
   File: Aarohi/Networking/ZohoApiConfiguration.cs
   Remediation: Removed constants. Dynamic DPAPI loading; fails closed if absent.
   Result: PASS (0 secrets in code or binary)

3. SEC-C-003 (Critical) - Clock Backdoor (ddMMyyyyHH) & IsDevPC
   Files: Aarohi/UserManagment/FormStartUp.cs, UserManager.cs
   Remediation: Deleted clock password & auto-fill. Implemented Option 2 DPAPI EmergencyDevVerifier.
   Result: PASS (Clock rejected; '1234' verified without database)

4. SEC-C-004 (Critical) - Plaintext Password Comparison
   Files: Aarohi/UserManagment/FormStartUp.cs, UserManager.cs
   Remediation: Routed to PasswordSecurity.VerifyPassword with PBKDF2 auto-rehash.
   Result: PASS (All comparisons use PBKDF2)

5. SEC-C-005 (Critical) - SQL Injection in DynamicClass Engine
   Files: Aarohi/Classes/DynamicClass/DynamicClass.Query.cs, UserManager.cs
   Remediation: Added SelectByColumn/SelectById. Parameterized all user-query calls.
   Result: PASS (100% parameterization enforced)

6. SEC-H-001 (High) - Unsalted Single-Pass SHA-256 Hashing
   Files: Aarohi/UserManagment/PasswordSecurity.cs, UserManager.cs, FormStartUp.cs
   Remediation: PBKDF2-HMAC-SHA256 (100k iter, 16B salt). DPAPI encrypted remember-me.
   Result: PASS (Unsalted SHA-256 eliminated)

7. SEC-H-003 (High) - Database TLS Certificate Validation Disabled
   Files: Aarohi/SQL/Global_Sql.cs, FormSqlConnectionManager.cs
   Remediation: Encrypt=true enforced. TrustServerCertificate defaults to 0 (Strict).
   Result: PASS (Strict TLS verification enforced)

8. SEC-H-005 (High) - Predictable OTP & Shared Static State
   Files: Aarohi/UserManagment/OtpService.cs, UserManager.cs
   Remediation: CSPRNG RandomNumberGenerator, per-user locks, 5m TTL, 3 attempts, 60s cooldown, ephemeral HMAC-SHA256.
   Result: PASS (Atomic single-use, race-free)

9. SEC-M-001 (Medium) - Admin Rights Based on Hardcoded Usernames
   Files: Aarohi/UserManagment/UserManager.cs, FormStartUp.cs
   Remediation: Username strings decoupled from authorization; permissions bound to database claims.
   Result: PASS (Role-based privilege checks)

10. SEC-M-003 (Medium) - Database Credentials in Commented Source
    File: Aarohi/SQL/FormSqlConnectionManager.cs
    Remediation: Deleted commented connection strings; encrypted saved passwords with DPAPI.
    Result: PASS (Zero database passwords in source)

11. SEC-M-008 (Medium) - Hardcoded Public DNS Resolvers
    File: Aarohi/Networking/MailHelpers.cs
    Remediation: Removed 8.8.8.8 and 1.1.1.1. Configured OS adapter DNS with 3s timeout and cache.
    Result: PASS (Split-DNS and corporate adapters supported)

12. SEC-L-001 (Low) - HTTP Clients Have No Explicit Timeout
    Files: Aarohi/Networking/ZohoOAuthService.cs, ZohoMailCleanupService.cs
    Remediation: Configured explicit 20-second timeout on static HttpClient instances.
    Result: PASS (Hangs prevented)

13. SEC-L-002 (Low) - Email Expunge Permanently Compile-Time Constant
    File: Aarohi/Networking/ZohoApiConfiguration.cs
    Remediation: Converted to runtime setting defaulting to false (Trash, not purge).
    Result: PASS (Safe default verified)

14. SEC-L-003 (Low) - Email Domain Validation Fail-Open Bug
    Files: Aarohi/Networking/MailHelpers.cs, UserManager.cs
    Remediation: EmailValidationResult tri-state (Valid, InvalidSyntax, DomainNotFound, LookupUnavailable).
    Result: PASS (No fail-open bypass)
