Aarohi Core Library Version History
================================================================================

1.0.14.49 - Added separate 'SaveWithAudit' method in DynamicClass.Crud.cs for safe, non-breaking change tracking.
1.0.14.50 - Removed LogEvent column mapping from database sink to fix silent DB write failures and enabled serilog_selflog.txt diagnostics.
1.0.14.51 - Added custom 'UserName' database column mapping and automated global username injection to all logs.
1.0.14.52 - Finalized Serilog database integration and verified successful schema and performance testing.
	  - Toggle Switch added for Network Sql Server Discovery
1.0.14.53 - Integrated Database Packager & Bootstrapping system.
	  - Added Developer Cloner Wizard (FormDatabaseCloner) to allow cloning, selective table data purging (wipe vs. keep), identity reseeding, and backup packaging.
	  - Added dynamic target directory argument self-healing in Aarohi.DbPackager to handle Windows backslash escaping errors.
	  - Integrated FormDbSplash visual splash screen to track SQL Server restore progress (0-100%) during first-run client database restoration.
	  - Enhanced database restore operations to copy backups to C:\Users\Public folder first, preventing operating system access-denied errors.
	  - Structured MSBuild targets inside NuGet package folder (build/Aarohi.targets) to automatically run the cloner wizard on rebuild without manual .csproj scripts.
1.0.14.54 - Implemented Transaction-Safe Native Database Migration Engine.
	  - Added automatic embedded SQL script discovery from calling assembly.
	  - Implemented GO-batch separator splitting for executing complex SQL scripts.
	  - Added tracking table dbo.AarohiSchemaVersions to register and track executed migrations.
	  - Integrated transaction safety with rollback on script failure.
1.0.14.71 - Enhanced DynamicCrudForm & DynamicAdderForm customization & layout control.
	  - Exposed direct Grid and DynamicClass properties on DynamicCrudForm to eliminate reflection/control-tree crawling.
	  - Exposed Add, Edit, Delete, and title controls for caller-defined styling and visibility.
	  - Added AutoEnforceWorkingAreaBounds toggle to honor caller-specified form dimensions and positions.
	  - Added AdderFormSize, AdderFormStartPosition, and ShowAdderAsDialog properties to control child Add/Edit forms.
	  - Added ConfigureAdderForm hook callback and RecordSaved/RecordDeleted lifecycle events.
	  - Integrated Aarohi.ExtendedUI.ExtendedMessageBox with a standard WinForms fallback (UseExtendedMessageBox).
	  - Added ShowSaveSuccessMessage toggle for silent saves with custom application toaster/banner support.
1.0.14.75 - Added CanDeleteRecord delegate hook on DynamicCrudForm.
	  - Enables external callers to validate, intercept, or block record deletion with custom domain messages while preserving 100% backward compatibility.
================================================================================

 1.0.14.54

Add username debounce autocomplete and eye button

 Introduce a 250ms debounce autocomplete for the username ComboBox: cache all usernames in _allUserNames, handle TextUpdate to filter items, and show the dropdown with  matched results. Replace the password toggle text button with a custom painted eye icon (with slash when visible) that toggles textBox2.UseSystemPasswordChar and  repaints. Wire up events and clear the password when a username is selected. Miscellaneous UI/event wiring and small formatting cleanups.
